# FitOS roadmap

## Phase 0 — Foundation (this increment)
- Monorepo: `apps/web`, `backend`, `packages/types`
- Provider and repository interfaces
- Initial Postgres + RLS migration
- Next.js 5-tab shell

## Phase 1 — Intelligence plumbing
- `ClaudeVisionAdapter` (tool-calling meal ID)
- Open Food Facts + USDA nutrition adapters
- Workout and activity persistence via Supabase

## Phase 2 — Workout engine
- Live logger, routines, volume/PRs, recovery map

## Phase 3 — Nutrition UX
- Camera, barcode, search, corrections loop

## Phase 4 — Cardio
- Live GPS, polyline map, GPX/FIT import

## Phase 5 — Social
- Feed, kudos, comments, leaderboards, share cards

## Phase 6 — Readiness
- Daily score, body logs, privacy flags

## Phase 10
- Native iOS (`apps/ios`) deferred
